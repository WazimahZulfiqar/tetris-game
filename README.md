# 🎮 Tetris Game — C++ & SFML

## 📌 About the Project
This project is a classic Tetris game developed in C++ using the SFML (Simple and Fast Multimedia Library). It recreates the classic block-stacking gameplay in which players position falling pieces to complete horizontal lines, clear rows, and keep the board from filling up.

The project demonstrates the use of C++ programming, game logic, graphics, functions, and a modular file structure.

## ✨ Features
- Classic Tetris gameplay
- Multiple falling block shapes
- Left and right movement
- Piece rotation
- Automatic downward movement
- Collision detection
- Horizontal line clearing
- Score tracking
- Game-over detection
- Graphical game interface
- Custom background and visual design

## 🛠️ Technologies Used
- C++
- SFML (Simple and Fast Multimedia Library)
- Visual Studio
- GitHub for version control and collaboration

## 📂 Project Structure

| File | Description |
|---|---|
| `main.cpp` | Main game execution and game loop |
| `functionality.cpp` | Game mechanics, movement, collision detection, and game logic |
| `functionality.h` | Declarations of game logic functions |
| `drawing.cpp` | Rendering the board, pieces, background, and game visuals |
| `drawing.h` | Declarations of drawing functions |
| `utils.h` | Shared constants, variables, and utility definitions |
| `pieces.h` | Tetromino shapes and piece-related data |

## 🎮 Gameplay
The objective is to arrange falling blocks to create complete horizontal lines. Completed lines disappear, allowing more blocks to fit on the board while increasing the player's score.

**Controls:**
- Move pieces left and right to position them.
- Rotate pieces to fit available spaces.
- Arrange blocks to complete horizontal lines.
- Keep the board from filling up to continue playing.
