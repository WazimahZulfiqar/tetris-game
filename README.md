# Tetris Game

A classic Tetris game developed in **C++ using SFML**. The game features falling tetrominoes, player-controlled movement, rotation, collision detection, line clearing, scoring, and a custom graphical interface.

## Features
- Seven different Tetris pieces
- Left and right movement
- Piece rotation
- Automatic piece falling
- Collision detection
- Line clearing
- Score and level system
- Pause and restart functionality
- Custom graphical interface

## Technologies Used
- C++
- SFML 3
- Visual Studio

## Project Status
Currently under development. The basic game structure and core gameplay functionality are being developed and tested.
